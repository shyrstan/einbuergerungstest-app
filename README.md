# Einbürgerungstest 2026 (Android)

Flutter app: all 310 official questions of the German naturalisation test (300 general + 10 per Bundesland),
exam simulation (33 questions / 60 min / pass at 17), explanations in DE/EN/TR/AR/RU/UK, offline.

- Content source: Anlage 1 EinbTestV (public domain as part of a federal regulation); answer keys cross-checked
  against the BAMF Online-Testcenter.
- `assets/data/questions.json` is generated by `tools/build_questions.py` from the `content/` folder.
- Builds run on GitHub Actions (`.github/workflows/build.yml`); artifacts: APK + AAB.

## Secrets / variables (GitHub → Settings → Secrets and variables → Actions)
Secrets: `ADMOB_APP_ID`, `ADMOB_INTERSTITIAL`, `ADMOB_REWARDED`, `ADMOB_BANNER`,
`KEYSTORE_B64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
Variables: `PRIVACY_URL`, `IMPRINT_URL`.
Without them the app builds with Google's test ad units and a debug signature.
